# Design principles

## 01 — Content leads

The page is the product. Navigation and tools should support it without competing with it.

## 02 — Make the next action clear

Use familiar words, visible focus, and a dependable keyboard path. A subtle interface can still be explicit.

## 03 — Preserve the user’s work

Prefer reversible changes. Never turn a visual preference into a destructive transformation of note content.

## 04 — Use colour with purpose

Blue carries structure and links. A restrained warm emphasis helps a strong phrase stand apart. A clean yellow highlight marks something to revisit.

## 05 — Test the quiet states

Empty, narrow, unfocused, and loading states deserve the same care as a full-size screenshot.
