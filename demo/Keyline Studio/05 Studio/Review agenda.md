# Review agenda

## Purpose

Decide whether the first reading loop is ready for a usability session. This is a decision meeting, not a tour of every screen.

## Thirty minutes

| Time | Topic |
| --- | --- |
| 0–5 | Restate the question and constraints |
| 5–15 | Walk through one realistic reading session |
| 15–25 | Identify task blockers and test assumptions |
| 25–30 | Assign the next actions and record the decision |

## Bring

[[Field Notes]], [[Usability plan]], and one example annotation.

## Leave with

A short list of changes, an owner for each, and an explicit answer to what remains uncertain.
