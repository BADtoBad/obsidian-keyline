# Quiet interfaces

Quiet does not mean invisible. A quiet interface makes important actions easy to find and lets secondary actions wait.

## Three observations

1. **Hierarchy should survive without colour.** Size, placement, and spacing do much of the work.
2. **Context can replace permanence.** A formatting tool is useful when text is selected, less useful when reading.
3. **Empty space needs a job.** It can separate ideas, but it should not reserve room for controls that are not there.

## A working hypothesis

==Reduce competition, not capability.== We can keep the same functions while changing when they appear.

## What to test

Compare a permanently visible action strip with contextual controls. Ask people to repeat the same task using pointer and keyboard. Record discoveries and misses separately.
