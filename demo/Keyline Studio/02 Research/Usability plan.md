# Usability plan

## Session outline

Allow thirty minutes. Begin with a short reading task, then ask the participant to leave a note, find it again, and return to its source.

## Tasks

1. Read the supplied page without changing the layout.
2. Mark one sentence and explain why it matters.
3. Add a related page using a link.
4. Find the note after a short interruption.

## Capture

Record task completion, hesitation, unintended actions, and participant comments. Do not treat silence as understanding. Ask follow-up questions after the task rather than guiding during it.

## Review

Separate failures of wording from failures of placement. Prioritise issues that block a task before polishing visual details.
