# Project brief

## Why this exists

Readers often save interesting passages but rarely return to them. Field Notes explores a smaller loop: read, connect, revisit. We are not trying to become an all-purpose library manager.

## First release

The first prototype contains a chapter reader, a short note beside a passage, and a review page showing three recent connections. Search, collaboration, and recommendations are deliberately outside the first release.

## What success looks like

- A first-time reader can attach a thought without instructions.
- The original passage remains visible while writing.
- A reader can return to the source with one action.

## Risks

Annotations may distract from reading. We will test a quiet default and an explicit reveal action, then compare completion and recall in the [[Usability plan]].
