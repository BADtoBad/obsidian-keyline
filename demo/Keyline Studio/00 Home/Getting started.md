# Welcome to Keyline

This fictional design studio is a place to explore Keyline’s light and dark surfaces, typography, and connected notes. Everything is editable. No real user information is included.

## Three places to begin

1. Open [[Studio showcase]] for the exact note shown in the current cover. Use the Studio workspace to restore the layout; Focus hides both sidebars.
2. Explore [[Field Notes]] to follow links between projects, research, and journals.
3. Open Settings → With Keyline to adjust typography, icons, and editing behaviour.

## Try it while editing

- In desktop Live Preview, press Enter for a new paragraph or Shift+Enter for a line break within it. Imported Markdown separators display as one paragraph gap. Turn off Typography → Paragraph editing to restore the earlier behavior.
- Select text to reveal the formatting toolbar.
- Type / on an empty line to open the insert menu.
- Type @ to choose a date or page, including directly after other text. Choose a menu item to insert it, or press Escape to keep the original text.
- Drag the handle beside a paragraph to move the entire block.

> [!note] English and Chinese interfaces
> The companion plugins follow Obsidian’s interface language. Restart after changing the language. Existing note contents, saved paths, and user-defined names are never translated.

The theme works on its own. With Keyline and Bucket Sidebar are optional companions. This updated example bundles Keyline 0.8.28, With Keyline 1.4.0 and Bucket Sidebar 0.5.8. The complete desktop setup requires Obsidian 1.13.7 or later. The previous Keyline interactions plugin is not bundled.
