# The studio collection

Every file here was made for this fictional demonstration. No private material or third-party book is included.

- [[Research brief.pdf]] — a one-page project brief.
- [[Reading rituals.epub]] — an original miniature ebook.
- [[Studio palette.svg]] — a vector colour study.
- [[Focus tone.wav]] — a quiet, synthetic two-second tone.
- [[Idea map.canvas]] — three connected research questions.

Keyline gives each file type a distinct icon and colour in the native File Explorer. Bucket currently collects Markdown notes and PDFs in several places without moving or duplicating them. Other formats are shown in the native File Explorer, not advertised as Bucket-supported entries. EPUB reading requires a compatible reader; the sample ebook is included to demonstrate file identity.
