KEYLINE STUDIO — EXAMPLE VAULT
Updated 2026-11-08

This fictional English Vault matches the current Keyline showcase images.
It contains Keyline 0.8.28, With Keyline 1.4.0 and Bucket Sidebar 0.5.8,
including the current report-style tables and file-type icons.
The full desktop setup requires Obsidian 1.13.7 or later.

OPEN THE EXAMPLE
1. Extract the ZIP and choose Open folder as vault in Obsidian.
2. Select the enclosed "Keyline Studio" folder, not its parent folder.
3. Review the bundled plugins and allow them to run in this example Vault.
4. After enabling plugins, click the bottom workspace control and choose
   Studio. This restores "00 Home/Studio showcase.md", the native File
   Explorer on the left and a single Bucket panel on the right. A new
   installation may briefly open an extra Bucket tab before this step.
5. Use the Focus workspace to hide both sidebars. Restore Studio to return.

The default appearance is light. Switch to dark in Settings > Appearance to
see the matching dark version. Both captures use the same layout. The diagonal
cover combines light and dark screenshots; it is not a split-colour app mode.
For the same interface labels, choose English in Obsidian and restart.
The example notes and saved names stay English in any interface language.
Folder expansion may need to be restored on a new device: expand "00 Home"
and "07 Assets" and leave the other top-level folders collapsed.

The example saves the same custom typography and 32px Bucket row height used
in the screenshots. These are showcase preferences, not new plugin defaults.
With Keyline and Bucket are optional companions; the theme works by itself.
The old Keyline interactions plugin is not included. Do not enable both
With Keyline and that older alternative in the same Vault.

TRY THE FEATURES
- In desktop Live Preview, press Enter for a paragraph or Shift+Enter for a
  line break. Imported paragraph separators display as one gap. Change this
  in Settings > With Keyline > Typography > Paragraph editing.
- Select text in Live Preview to use the nearby formatting toolbar.
- Type @, then choose a date or page with the mouse or keyboard.
- Type / on an empty line to open the insert menu.
- Explore the pinned note, Studio/Personal spaces and Bucket groups.
- Open "00 Home/Markdown playground.md" for other Markdown examples.

FILES AND COMPATIBILITY
All 27 notes and sample assets are fictional. The EPUB sample needs a separate
reader to open inside Obsidian; a file-type icon does not add a file reader.
Mobile support remains Beta. This example's two-sidebar layout is prepared
for desktop, and is not a claim of physical phone or tablet acceptance.
Obsidian 1.7.7 cannot run the included With Keyline build.

Keep this as a separate example Vault. Do not copy its .obsidian folder over
an existing personal Vault, because that would replace your settings.
Licences and third-party notices are included alongside each bundled component.
No personal notes, application profiles, credentials or recovery files are
included. Older example downloads remain available in the release history.
